# Привязка к флагману КНС-1

Код ST, который соединяет ядро шлюза MQTT (`src/` репозитория) с переменными флагмана
kns-pump-station, и его тесты. Раскладка — как у флагмана: при встраивании `flagship/src/` копируется в
его `src/`, `flagship/tests/` — в его `tests/`
([docs/MANUAL_STEPS.md, раздел 11](../docs/MANUAL_STEPS.md#11-встраивание-во-флагман)).

| Объект | Что делает | Откуда |
|---|---|---|
| `src/POUs/Iiot/PRG_Iiot/` | программа обмена: время, клиент MQTT, связь, телеметрия, тревоги, шлюз команд; задача `MainTask` флагмана после `PRG_Devices` | вручную |
| `src/POUs/Iiot/FB_IiotKnsMap/` | значения и качество метрик из `GVL_Devices`, `GVL_IO`, `GVL_Station`; слова тревог устройств и станции; запись принятых команд в `GVL_Hmi` и `GVL_Station`; счётчик и результат команды | `python tools_project/gen_plc_iiot.py` из `schema/` |
| `tests/POUs/Iiot/FB_IiotKnsMap_Test/` | тесты coUnit привязки на настоящих переменных флагмана: метрики и инверсия K1, слово тревог станции, запись команд в `GVL_Hmi` и `GVL_Station`, счётчик и результат команды, `PRG_Iiot` с подменным клиентом до ответа `accepted` на команду станции | вручную |

Здесь этот код не компилируется: ему нужны типы `PL.*` библиотеки plc-process-lib и глобальные списки
флагмана. Вместо этого `tests_stack/test_flagship_binding.py` проверяет по снимку интерфейса флагмана
(`schema/source/flagship_symbols.json`), что каждый путь — настоящая переменная флагмана, выгружаемая в
символы OPC UA, с тем же типом, а запись идёт только в структуры команд; st_lint проверяет оформление
(`tools/check/st_lint.toml`, `paths`). Сборка и тесты — во флагмане: `python tools_project/flagship_embed.py
--repo <рабочая копия флагмана>`, затем его `cds.py build` и `cds.py test`. Прогон 19.10.2026 (флагман
`58fc169`): сборка без ошибок и предупреждений, 423 теста coUnit из 423, из них 5 — `FB_IiotKnsMap_Test`
([docs/TEST_REPORT.md](../docs/TEST_REPORT.md#встраивание-во-флагман-и-стенд-против-его-рантайма)).

Генерируемые файлы руками не правятся: после изменения `schema/` или снимка флагмана —
`python tools_project/gen_plc_iiot.py`; `--check` — проверка актуальности (CI).
