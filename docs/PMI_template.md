## Проверки

Итог: «соответствует» / «не соответствует» (с номером замечания) / «не проверялось».

| № | Проверка | Действия | Ожидаемый результат | Итог |
|---|---|---|---|---|
| 1 | Ограничение уставки диапазоном | В режиме `Auto` записать онлайн `PRG_Main.stCmd.rSetpoint_pct := 150` | `PRG_Main.stSts.rSetpointUsed_pct = 100` (верхняя граница `GVL_Const.EXAMPLE_SP_MAX_PCT`) | |
| 2 | Безопасное состояние при отказе измерения и квитирование | В режиме `Auto` при включённом насосе записать `PRG_Main.xLevelValid := FALSE`; затем `xLevelValid := TRUE` и `stCmd.xAck := TRUE` | После отказа: `xPumpOn = FALSE`, `stSts.xFault = TRUE`. После квитирования: `stSts.xFault = FALSE`, `stCmd.xAck` сброшен программой, насос снова работает по уровню | |
